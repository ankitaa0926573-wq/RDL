Library Document Repository

Free, open-source software for preserving and managing a library's own internal records — invoices, vendor agreements, policies, committee minutes, NAAC and audit documents — from receipt to secure disposal.

Built on the seven-phase LDR framework

Every document follows a controlled lifecycle aligned with the OAIS reference model, the Records Continuum Model and the DCC Curation Lifecycle Model, so each record has an accountable entry, a verified life and a documented exit.

Unique ID, source and custodian

Secure Disposal

Approved, erased, certified

Features

Designed for school, college and university libraries preparing for audits, inspections and accreditation.

Full-text search

Find records by ID, title, vendor, reference number, keyword, year or the text inside PDFs, Word and Excel files. Scanned pages become searchable with OCR.

Role-based access

Administrator, Super Librarian, Cataloguer, Technical Staff, Library Staff and view-only roles. Confidential records open only with the Super Librarian's permission.

Tamper-evident audit trail

Every login, upload, view, download, approval and disposal is logged in a hash-chained trail that can be verified and exported for auditors.

Retention schedules

Retention periods per category (invoices 8 years, policies permanent…), automatic expiry dates, daily alerts and recorded review decisions.

Integrity & backups

SHA-256 fixity checks every day, preservation master plus access copy, and an automatic daily backup of the database and files.

Disposal certificates

Two-person approval and secure erasure, with a printable certificate listing the reason, the people involved and the checksums of the destroyed files.

Download & install

Install once on one library computer (the server). Every staff computer then uses LDR in a web browser over the library network — nothing to install on them.

⬇ Download LDR

What's new

Already using LDR? You don't need to download again — the administrator gets an "Update available" message inside LDR (Settings & backup → Software updates) and installs it with one click.

Windows

  1. Install Python 3.10+. Tick "Add python.exe to PATH".
  2. Unzip LDR to C:\LDR.
  3. Run install_windows.bat (as administrator to open the firewall port).
  4. Start it with the LDR Server desktop icon and complete the setup page.
  5. Optional: autostart_windows.bat starts it automatically at boot; install Tesseract OCR for searchable scans.

Linux (Ubuntu/Debian)

unzip LDR-x.y.z.zip
cd LDR-x.y.z
bash install_linux.sh

Installs OCR, registers a systemd service and starts LDR automatically at boot.

Docker

cd LDR-x.y.z
docker compose up -d

Data, configuration and backups are kept in the ./data folder.

System requirements

ServerAny Windows 10/11 or Linux PC; 4 GB RAM; disk space for your documents (1 GB holds roughly 3,000–6,000 scanned pages)
ClientsAny modern browser (Chrome, Edge, Firefox) on the same network
SoftwarePython 3.10+ (Windows/Linux) or Docker; Tesseract OCR is optional
DatabaseBuilt-in SQLite (no setup); PostgreSQL optional for large installations
